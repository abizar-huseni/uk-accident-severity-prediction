# UK Accident Severity Prediction

An MSc Machine Learning project predicting road accident severity in the UK, using Random Forest and Gradient Boosting on Department for Transport data.

## Overview
This project builds classification models to predict the severity of road accidents in the UK, using historical collision data published by the Department for Transport.

## Tools
1. Python (pandas, scikit learn)
2. Random Forest classifier
3. Gradient Boosting classifier

## Status
This repository is a work in progress.
